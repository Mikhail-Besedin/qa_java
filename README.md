# Sprint 6 
##  Описание проекта
Автотесты для системы учета животных семейства кошачьих. Проверяет:
- Поведение классов `Feline`, `Cat` и `Lion`


##  Технический стек
- **Язык**: Java 11
- **Тестирование**: JUnit 4
- **Мокирование**: Mockito
- **Покрытие**: JaCoCo (100% для Feline/Cat/Lion)
- **Сборка**: Maven

## Запуск 

 `mvn clean test` 


## Отчет о покрытии:
target/site/jacoco/index.html


## Особенности тестирования
100% покрытие для Feline, Cat и Lion

Все тесты независимы друг от друга

Параметризованные тесты вынесены в отдельный класс

Использование инъекции зависимостей
